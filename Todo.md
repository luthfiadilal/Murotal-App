**Objective:**

Create a mobile music player application that utilizes the publicly available Quran API (https://alquran.cloud)

**Required Functionality:**

*   **Search**: Allow users to search for songs by title or artist.
*   **Playback Control**: Implement standard playback functions: play, pause, resume.
*   **Progress Display**: Show the song's total duration and current playback position using a progress bar.
*   **Seeking**: Enable users to navigate through the song using a slider.

**Evaluation Criteria:**

*   **State Management**: Employ either BLoC, GetX, or MobX for state management.
*   **Documentation**: Provide a comprehensive summary of your application in a README.md file.
*   **Code Quality**: Demonstrate clean code design, a well-organized project structure, clear readability, and thorough documentation.
*   **Library Usage**: While you're free to use libraries, prioritize your own implementation to showcase your skills.
*   **User Interface**: Design a simple and effective user interface.
*   **Submission**: Submit your project via a Git repository (GitLab, GitHub, Bitbucket, etc.).
*   **Visual Documentation**: Include screenshots or a screen recording of your application.

**Bonus Considerations:**

*   Implement unit and widget tests.
*   Add comprehensive code comments.
*   Enhance the README.md with detailed information.
*   Create a custom app icon.
